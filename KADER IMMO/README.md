# Agence immobilière Kader

Site statique responsive pour l'agence immobilière Kader à Oran.

## Lancer le site

Depuis ce dossier, utilisez l'une de ces commandes :

```bash
npm start
```

ou :

```bash
python3 -m http.server 8080
```

Ouvrez ensuite `http://localhost:8080`.

Le site fonctionne également en ouvrant directement `index.html` dans un navigateur.

## Administration de démonstration

Ouvrez `#/admin` après l'adresse du site, puis connectez-vous avec :

- Identifiant : `admin@kader.dz`
- Mot de passe : `Kader2026!`

Les propriétés et les images ajoutées dans cette version de démonstration sont enregistrées uniquement dans le navigateur. Une mise en production doit connecter l'administration à Firebase/Cloudinary ou à une API équivalente.
